# Funciones del módulo "json" de la biblioteca estándar.
# Cada línea es: nombre | parámetros separados por comas (0 si no tiene) | descripción en español | ejemplo de una línea
a_json | valor | convierte un valor (número, texto, lógico, nada, lista o lista con claves) en texto JSON | a_json([1, "dos"])   # [1,"dos"]
leer_json | json, camino | saca un dato de un texto JSON siguiendo un camino con puntos y corchetes; un objeto se devuelve como texto JSON | leer_json(respuesta, "usuario.nombre")
listar_claves_json | json, camino | lista las claves del objeto que hay en ese camino ("" para el principal) | listar_claves_json(respuesta, "")
desde_json | json | convierte un texto JSON entero en valores: los objetos pasan a listas con claves | sea datos = desde_json(respuesta)   # datos["usuario"]["nombre"]
